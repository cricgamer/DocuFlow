Client-Side Architecture Guarantee

100% Zero-Backend Architecture: PageZero contains no backend server, no database, and no telemetry.

How it works: All file reading, PDF merging, DOCX parsing, vector watermarking, and page manipulations are executed entirely in the client-side JavaScript sandbox via WebAssembly and Web Workers.

Free GitHub Pages Hosting: Because there are no backend APIs required, this entire application runs on any static host at $0 cost forever.
